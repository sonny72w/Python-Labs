# Python-Labs
<h2>Description</h2>
Project consists of a creation of a website for an manage security provider and the continuous update of that website and the creation of a duty board website that help teachers or lecturers assign, track and manage student responsibilities in an organized and effective way. <br />


<h2>Languages and Utilities Used</h2>

- <b>Python 3 and Flask: The core web framework used to handle routing, requests
and rendering HTML templates.</b>

-  <b>Flask-SQLAlchemy: An ORM (Object Relational Mapper) used to interact with
the SQLite database using Python classes instead of raw SQL.</b>

-  <b>Flask Login: Manages user sessions, login state and protects routes so only
authenticated users can access them.</b>

-  <b>Flask WTF and WTForms: Used to build and validate the login and registration
forms including CSRF protection.</b>

-  <b>Flask Bcrypt: Handles secure password hashing so plain text passwords are
never stored in the database.</b>

-  <b>SQLite: A lightweight file based database used to store user accounts and duty
assignments.</b>

-  <b>Jinja2: Flasks built in templating engine used to dynamically render HTML
pages with data from the database</b>

- <b>Bootstrap 5 and CSS: Used for styling the interface, including the responsive
navbar, tables and form layout.</b>


<h2>Environments Used </h2>

- <b>Windows 11</b> (21H2)

<h2>Python labs:</h2>

- <b>Lab 1 to 5 the creation of msp and updates</b>

- <b>Final Lab the creation duty board</b>
